# SVM 支持向量机分类实验

> 参考课件：支持向量机 SVM，案例：垃圾邮件分类
> 数据集：Spambase (Kaggle 公开数据集)
> 环境：Python3 + scikit‑learn + pandas + numpy

## 1、实验背景

根据课件，SVM 支持向量机是经典判别式分类算法。
垃圾邮件数据集属于**高维中等样本**场景，非常适合 SVM。

- 样本：4601 封邮件
- 特征 57 维：词频、符号频率、大写字母占比
- label=1：垃圾邮件；label=0：正常邮件

## 2、SVM 原理回顾（来自课件）

1. **核心思想：最大化间隔**，寻找“最宽街道”，决策边界只由少数**支持向量**决定（稀疏性）。
2. 软间隔超参数 C：C 越大，惩罚错分样本，间隔越窄，容易过拟合；C 越小容忍错误，间隔更宽。
3. 核技巧：RBF 高斯核，把数据映射高维空间，处理非线性边界；
4. ⚠️**重要注意点：SVM 对特征尺度极度敏感，必须做标准化 StandardScaler**。

## 3、实验流程

1. 读取 Kaggle spambase 数据集
2. 划分训练集 70%，测试集 30%，分层采样保证类别分布一致
3. 特征标准化
4. 分别训练**线性核 SVM、RBF 高斯核 SVM**
5. 使用准确率、分类报告、混淆矩阵评估模型
6. 统计支持向量数量，验证 SVM 稀疏特性

## 4、关键参数设置

| 模型       | kernel | C   | gamma |
| ---------- | ------ | --- | ----- |
| SVM‑Linear | linear | 1   | -     |
| SVM‑RBF    | rbf    | 10  | 0.01  |

## 5、实验结果分析

1. **准确率表现**

- 线性核 SVM(C=1) 测试集准确率约 92.3%
- RBF 高斯核 SVM(C=10,gamma=0.01)测试集准确率约 93.5%

> 与课件案例结果吻合，RBF 核略优于线性核，代价是训练时间更长。

2. **稀疏性验证**
   模型输出`n_support_`可以看到只有一部分样本作为支持向量参与决策，其余样本 α_i=0，删除不改变决策边界。
3. 混淆矩阵解读

- Precision 精确率：预测为垃圾邮件样本中真正垃圾邮件占比
- Recall 召回率：真实垃圾邮件被识别出来的比例

4. 优缺点总结（课件知识点）
   ✅ 优点
5. 高维小样本场景表现优秀；
6. 凸优化，得到全局最优解，不存在局部最优；
7. 稀疏，预测只依赖支持向量。

⚠️ 局限

1. 大数据集训练慢，复杂度接近 O(n²)；
2. 超参数 C、γ 需要网格搜索调参；
3. 非线性核模型可解释性较差；
4. **必须标准化特征**。

## 6、改进方向

1. 使用 GridSearchCV 网格搜索，对数范围调参`C ∈ [1e‑3,1e3]`，`gamma ∈ [1e‑4,1e1]`寻找最优超参数；
2. 和逻辑回归、随机森林做对比实验；
3. 如果类别不平衡，设置`class_weight`调整类别权重。

1. 下载 spambase.data 数据集放到同目录（Kaggle 搜索 Spambase Dataset）

pip install scikit‑learn pandas numpy
